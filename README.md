# Axon-Myelin-Segmentation-Pipeline

A deep learning–based segmentation pipeline for **axon**, **myelin**, and **background** in **light microscopy (LM)** images of peripheral nerve cross-sections.

---

## Overview
This project aims to design and evaluate a robust **multi-class segmentation model** optimized for LM images, addressing challenges such as:
- Lower spatial resolution compared to EM
- Variable staining and illumination
- Irregular and overlapping tissue morphology

The model outputs **axon**, **myelin**, and **background** classes to enable accurate morphometric analysis for peripheral nerve research.
